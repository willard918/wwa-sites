# WWA envelope seal

`wwa-seal.svg` is the artwork (black on white, 1-5/8 in round). `wwa-seal.pdf` is a 4 in vector print of it; `wwa-seal-3000px.png` is a 3000 px bitmap for vendors that only accept images.

- Line weights are at least ~0.5 mm at 1-5/8 in and the type is bold serif at about 7 pt or larger, so it should emboss cleanly. The text in the SVG/PDF is live type (Georgia): if a vendor wants outlines, ask them to convert it, or send the PNG.
- Order a *custom logo/art* embosser, round, 1-5/8 in (envelope flaps need a handheld/pocket model with enough reach). Check which way the impression is made (from the bottom for most) and ask for a proof.
- Do not use your official architect's seal for envelopes; that is a separate, regulated stamp.
